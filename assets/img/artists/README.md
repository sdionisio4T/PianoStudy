# Imagen de portada de Artistas

`piano-jazz-cover.jpg` es una portada local provisional para las fichas de
artistas. Se usa porque las imágenes históricas remotas de Wikimedia fallan en
diversas redes y no deben dejar la interfaz vacía.

Fuente: [Unsplash](https://unsplash.com/photos/a-close-up-of-a-piano-with-a-blurry-background-7mF-dRQV-ds)

Cuando se curen retratos individuales con licencia y atribución verificadas,
guardarlos en esta carpeta y añadir la atribución correspondiente aquí.
